 🎵 简听音乐播放器

一个基于 PyQt5 的本地音乐播放器，支持歌词同步显示、自定义背景、氛围特效等功能。
  功能特点
- 🎵 **本地音乐播放** - 自动扫描并加载 MP3 文件
- 📝 **歌词同步显示** - 支持 LRC 歌词文件和嵌入歌词
- 🎨 **自定义背景** - 自由更换背景图片
- 🌧️ **氛围特效** - 下雨、下雪等环境特效
- ⛶ **全屏播放模式** - 沉浸式音乐体验
- 🎚️ **音量控制** - 直观的音量滑块
- ⏭️ **自动下一首** - 播放结束后自动切换
- 🗑️ **歌曲隐藏** - 隐藏不想显示的歌曲
- 🔄 **刷新列表** - 一键刷新音乐库
使用前要下载
VLC media player 软件
